# Clementine CLI Documentation

To deposit Citrea using Clementine bridge, first you need to have a Citrea
address, which is in Etherium address format. You can either connect your
existing wallet to Citrea at [citrea.xyz/bridge](https://citrea.xyz/bridge).
Than optionally, you can [import your private key](wallet.md#import-private-key)
to the local Clementine wallet. Or, you can [create a new wallet](wallet.md#create-wallet)
locally.
